# Помощь для покупателей

Audience: public
Last updated: 2026-07-03
Verified against: 64a177a

Эта страница для клиентов, которые пишут бизнесу через его Telegram-бот. Каждый
бизнес в Dealio работает через собственного бота. Скачивать ничего не нужно:
откройте ссылку на бота, нажмите «Старт» и пользуйтесь.

## Что умеет бот

В зависимости от бизнеса бот позволяет:

- записаться на услугу;
- посмотреть статус вашего проекта.

## Согласие при первом обращении

При первом обращении бот попросит вас дать согласие на обработку персональных
данных. Без согласия продолжить нельзя. Подробности о том, какие данные
обрабатываются и как, описаны в политике конфиденциальности:
https://dealio.uz/privacy

## Как проверить статус

- Записи: нажмите «Мои записи» в боте.
- Проекты: нажмите «Мои проекты» в боте.

## Записи и напоминания

Когда вы записываетесь, бот присылает подтверждение с услугой, датой и временем.
Оплата за услугу обычно на месте.

За сутки до записи бот пришлёт напоминание. Если запись нужно отменить, ответьте на
сообщение с напоминанием словом CANCEL. Бот отменит вашу ближайшую запись и
подтвердит отмену.

## Команды

- /start открыть бота заново и вернуться в меню.
- /help показать помощь.
- /appointments посмотреть свои записи (для услуг).
- /projects посмотреть свои проекты (для фриланс-проектов).
- /deletedata удалить мои данные безвозвратно.

Сменить язык бота можно через кнопку смены языка в меню.

## Удаление данных

Команда /deletedata удаляет ваши персональные данные без возможности восстановления.
Бот сначала попросит подтверждение. После подтверждения ваше имя, телефон, адрес и
данные Telegram стираются. История ваших записей и проектов (номера, суммы, даты и
статус) остаётся у бизнеса для бухгалтерских и юридических целей, но без ваших личных
данных.

Подробнее о ваших данных: https://dealio.uz/privacy
