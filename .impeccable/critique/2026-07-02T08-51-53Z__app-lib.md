## Priority Issues

1. **[P0] No accessibility layer; unusable with TalkBack.** Zero Semantics/semanticLabel in app/lib; all controls are raw GestureDetectors (`app_button.dart:166-172`, `app_checkbox.dart:39-44`, `app_switch.dart:32-34`, `floating_tab_bar.dart:183-188`). Fix: wrap the 5 shared primitives in Semantics. → /impeccable harden
2. **[P1] Raw exception strings on every screen.** `_ErrorView(message: e.toString())` ~10×. Fix: one shared AppErrorState mapping to 3-4 localized messages; promote `customer_detail_screen.dart:1240-1250` pattern. → /impeccable clarify + harden
3. **[P1] Dates are English in uz/ru.** No DateFormat locale anywhere; spec requires "15 yanvar 2026 / 15 января 2026". → /impeccable harden
4. **[P1] Money loop has no guardrails.** (a) Card number free-text, no formatter/validation (`settings_screen.dart:525-534`); (b) Confirm payment: single tap, no confirm, no success feedback, irreversible (`order_detail_screen.dart:579-585,631-651`). → /impeccable harden
5. **[P1] Customer detail has no history — in a CRM.** No orders/appointments/projects list (`customer_detail_screen.dart:141-168`) despite backend support. → /impeccable shape
6. **[P2] Icon vocabulary undermines low-literacy users** (gear=edit, plus-circle=copy, paid-check=selected, person=phone). → /impeccable clarify
7. **[P2] Spinner-only loading + Settings sprawl** (14 sections → 4-5 collapsed groups; add skeletons mirroring web). → /impeccable polish
8. **[P3] Polish:** danger button glows blue (`app_button.dart:111`); hardcoded localhost proposal link (`project_detail_screen.dart:292-295`); timeline dots always accent.
