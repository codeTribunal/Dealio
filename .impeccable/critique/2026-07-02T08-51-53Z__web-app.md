## Priority Issues

1. **[P0] Core money screens ignore the existing i18n system.** Orders (3 `t()`), order detail (3), projects/staff/analytics/onboarding (0) vs a complete 279-key uz/ru/en dictionary. Fix: mechanical `t()` pass; keys mostly exist. → /impeccable harden
2. **[P1] Payment confirmation is fragile and mute.** No try/catch (`orders/[id]/page.tsx:70-84`) → failure strands buttons; no amount restatement, no undo, no success feedback; silent milestone/invoice failures (`projects/page.tsx:209-229`). → /impeccable harden
3. **[P1] Keyboard/AT users can't operate list→detail flows.** Clickable `<div>` cards without role/tabIndex (`catalog/page.tsx:251-256`, `appointments/page.tsx:547-556`, `projects/page.tsx:430-434`, `staff/page.tsx:193-196`); slide-overs lack dialog semantics/focus trap/Escape (6 hand-rolled copies). → /impeccable harden
4. **[P2] Banned side-stripe status borders** on appointment cards duplicating the badge (`appointments/page.tsx:38-44`). → /impeccable polish
5. **[P2] `--text-3` ≈2.5:1 and `--text-2` ≈4.2:1 fail WCAG AA** (`tokens.css:46-48`), used for meta text and inactive mobile tabs. Fix: darken to ~L52%/~L47%. → /impeccable polish
